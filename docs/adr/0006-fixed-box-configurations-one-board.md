# A short menu of fixed Box configurations, built on one board

We sell a few fixed configurations instead of custom-built Boxes. The board is designed for the highest rating we sell, and lower tiers use different current-sensing parts, wiring and breakers. A bus connector and addressing are designed into the first controller so extra Socket modules can be added later, but v1 ships as a fixed 4-Socket Box. Custom hardware per customer would remove the "mostly software" advantage because each variant needs its own testing and certification.
