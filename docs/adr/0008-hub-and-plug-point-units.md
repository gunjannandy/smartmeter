# The Box is a hub; each plug point is its own small unit

The Box holds the controller (Bluetooth and Wi-Fi), the main breaker and the earth-leakage protector. Each plug point is a small separate unit with its own meter, relay and chip, mounted next to a parking spot and joined to the Box by one power-and-data cable. This lets a Host add plug points one at a time and place them where vehicles actually park, instead of being limited by the number of sockets in one enclosure. We rejected putting every meter and relay in the Box with plain sockets on long cords: the Box would cap the number of sockets, and one metered socket must never feed a multi-outlet strip because its outlets could not be metered separately. The cost is more mains-voltage parts outside the Box, so each plug-point unit needs its own enclosure rating and protection. The first bench prototype may still use a single enclosure because it is cheapest to build; the target design is the hub with plug-point units. Supersedes ADR 0006.
