# Contributing

- Open an issue for any design question before writing code. Say which area it touches: hardware, firmware, host app, driver app, or cloud.
- Use the words in [GLOSSARY.md](GLOSSARY.md). If a term is missing or fuzzy, propose a change to it.
- A decision that is hard to reverse, surprising, and a real trade-off gets a short record in [docs/adr](docs/adr) (one paragraph is fine).
- Anything that switches mains power is safety-critical. Hardware and firmware changes need a second reviewer.
