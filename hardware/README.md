# Hardware

PCB, parts list, enclosure, calibration and safety. Constraints so far: AC only; certified relay, metering chip and protection (MCB, RCCB, earthing) in a compliant enclosure; one board designed for the highest rating; expansion bus designed in; factory calibration against a reference meter; a status LED per Socket. See [ADR 0006](../docs/adr/0006-fixed-box-configurations-one-board.md).
